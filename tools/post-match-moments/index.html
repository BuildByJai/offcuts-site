How it works

Pick one of the eight covered clubs, then a finished match. The tool pulls that fixture's real goals, cards, subs, shot and possession stats, and post-match ratings from API-Football, then an AI pass turns the data into a handful of talking-point moments with short scripts. Each moment renders as an animated pitch clip you can narrate over or post with the built-in subtitles.

Why only 8 clubs?

Keeping the list fixed keeps the picker simple and keeps the AI pass working with a consistent, familiar set of squads rather than open-ended fixture search.

Are the player positions real?

No — they're an illustrative sketch built from event data and stats, not tracked positional data. Use them as a storytelling aid, not a tactical record.

Data via API-Football. Moments and scripts generated by AI from real match events, stats, and post-match ratings — always verify before publishing. Not affiliated with the Premier League or any club.
