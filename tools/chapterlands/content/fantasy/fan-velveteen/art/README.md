# The Velveteen Rabbit — art

All art for this district is our own, drawn in code in the town's blocky toon style:

- **Palette:** `palette.json` (the same colours as `book.json` → `theme.palette`): warm nursery browns, cream walls and a rosy roof.
- **Props:** the District Kit prop library (`kit/props.js`): nursery blocks, beds, cupboards, bookcases.
- **Characters:** `js/critters.js`: the Skin Horse (a balding brown toy horse), the Boy, the wild rabbits and the Fairy, all built from the book's descriptions.
- **Items:** emoji badges (toy engine, clockwork mouse, model boat, lion, china dog, oranges).

No illustrations are used. (William Nicholson's 1922 illustrations are public domain and could be added here later.)
