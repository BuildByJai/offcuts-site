# The Adventures of Sherlock Holmes — art

All art for this district is our own, drawn in code in the town's blocky toon style: the palette in `palette.json` (same as `book.json` → `theme.palette`), the District Kit prop library (`kit/props.js`), blocky characters from `js/critters.js` built from the book's own descriptions, and emoji badges for items. No film designs and no third-party illustrations are used.
